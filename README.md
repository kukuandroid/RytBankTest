

## Get started

1. Install/Verify expo and project dependencies
 ```
 npx expo -h && npx expo start
 ```

2. Change API endpoint

 ```
 const API_BASE_URL = 'http://192.168.1.8:3000/api'; // Replace with your actual ip address of the same wifi network
 ```

3. Start the app
 ```
 npx expo start
 ```

4. Use real device to test
 ```
 Use expo go (Android ) app by scanning the QRCode
 ```

During the completion of this assessment, I was concurrently managing ongoing responsibilities at my current company, including the deployment of a banking application, while also balancing personal commitments and family time.
